# UIStore — Premium React Component Marketplace

"Build Faster. Ship Sooner."

UIStore is a production-ready marketplace where developers purchase high-quality React components using a credit-based system.

## 🚀 Technology Stack
- **Vite** for lightning-fast development
- **React 18** (JavaScript) for component architecture
- **Tailwind CSS** for modern, utility-first styling
- **Framer Motion** for premium interactive animations
- **Lucide React** for consistent iconography

## 📦 Key Features
- **Production-Ready**: Every component includes logic, styling, and responsiveness.
- **Interactive Sandbox**: Preview components across Desktop, Tablet, and Mobile.
- **Credit System**: Transparent pricing with starter to agency packages.
- **Community First**: Share your own components and access a massive free gallery.

## 📂 Project Structure
- `index.html`: Marketing-focused landing page with Framer-style animations.
- `marketplace.html`: Component discovery and category filtering.
- `component-detail.html`: Deep dive into component logic and source code.
- `dashboard.html`: User management and purchase history.
- `admin-dashboard.html`: Platform administration.
- `components/`: Reusable React components ready for integration.

## 🛠️ Getting Started
1. Install dependencies: `npm install`
2. Start dev server: `npm run dev`
3. Build for production: `npm run build`
